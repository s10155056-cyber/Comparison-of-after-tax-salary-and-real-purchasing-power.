## index.html 裡的程式結構

整份檔案是單一 HTML，`<style>` 與 `<script>` 內嵌其中。`<script>` 區塊分四段：

| 段落 | 內容 | 行數量級 |
|---|---|---|
| **1. 資料層** | 聯邦／加州／台灣的稅率級距、FICA、保費級距、6 個城市的生活成本 | 約 200 行 |
| **2. 計算核心** | `progressiveTax()`、`laborInsuranceBase()`、`computeRegion()`、`salaryForPP()` | 約 130 行 |
| **3. 格式化** | `fmtMoney()` / `fmtMoney2()` / `fmtNum()` / `fmtPct()` / `esc()` | 約 30 行 |
| **4. 狀態與 UI** | `state`、`render()`、`renderStats()`、`renderCompare()`、`renderDuel()`、事件綁定 | 約 200 行 |

### 幾個值得先看的函式

- **`computeRegion(regionId, annualSalary, filing, fx)`** — 核心。回傳一個物件，含稅後年收入／月收入、每一項稅的明細、基本生活成本、可儲蓄金額與儲蓄率、生活費覆蓋倍數、實質購買力指數、有效稅率。美國與台灣是兩條分支。
- **`progressiveTax(income, brackets)`** — 級距累進稅的通用實作，只要餵 `[{upTo, rate}, ...]`。
- **`salaryForPP(regionId, filing, targetPP, fx)`** — 二分法求解「要多少年薪才有目標購買力」。購買力指數對薪資是單調遞增的，所以可以直接二分。
- **`renderDuel()`** — 雙城對決，含等值薪資那兩條。

### 資料要從哪裡看

所有稅率與生活成本係數都集中在 `<script>` 最上方的 `FED_2026` / `FICA_2026` / `CA_2026` / `TW_114` / `REGIONS` 幾個物件裡，每個數字旁邊都註了出處註解。想換年度、換幣別、增減城市，改這幾個物件就好，不必碰計算邏輯。

## 這支工具怎麼算

1. **稅後月收入** — 先把輸入的年薪換算成當地貨幣，再依該地稅制逐項扣除。
2. **生活成本調整後的實質購買力** — 兩個角度：
   - **購買力指數**：稅後月收入換算成 USD 後，除以 Numbeo「生活成本＋房租指數 ÷ 100」。數字代表「以紐約物價計算，你的稅後月收入相當於多少」。
   - **生活費覆蓋倍數**：稅後月收入 ÷ 當地基本生活費。無需匯率，天然可跨城市比較。
3. **可儲蓄金額** — 稅後月收入 − 當地基本生活成本，另附儲蓄率。基本生活成本 = Numbeo「單人日常開支（不含房租）」+「市中心一房租金」，使用者可自行覆寫。

## 跑驗收測試

需要 Node.js 與 Playwright 的 Chromium：

```bash
cd demo
node tools/verify.js
```

腳本會實際開啟 `index.html`、點擊預設組合、讀取畫面上的數字，與腳本內獨立手算的預期值比對；同時檢查 console error、外部資源請求、以及行動／平板視窗的水平溢出。全部通過時退出碼為 `0`。

```
矽谷 US$150,000 → 稅後月收入 $8,523.35、有效稅率 31.8%、可儲蓄 $3,802.35
台北 NT$2,000,000 → 稅後月收入 NT$149,345、有效稅率 10.4%、可儲蓄 NT$99,206
德州  US$80,000  → 稅後月收入 $5,425.83、有效稅率 18.6%、可儲蓄 $2,228.83
```

## 資料來源

完整清單與出處在 App 內「資料來源與計算假設」區塊，也在 `CHANGELOG.md` 第 0 輪。

**已查證**：IRS Rev. Proc. 2025-32（2026 聯邦級距）、SSA 2026 COLA Fact Sheet 與 IRS Topic 751（FICA）、FTB 2026 年 10 月 Tax News 加州 Schedule X/Y、EDD DE 44（SDI 1.3%）、德州憲法第 VIII 條第 24 節（無州所得稅）、財政部台財稅字第 11304670610 號（台灣 114 年度綜合所得稅）、勞動部與健保署 115 年度勞健保勞退級距、中央銀行 2026/10/27 收盤匯率（1 USD = 32.45 TWD）、Numbeo 2026 成本快照。

**⚠️ 兩項已採用的假設**（App 內亦有揭露）：

1. **台灣 115 年度（2026 所得）公告尚未發布** — 財政部預計 2026 年 11 月公告，故沿用最新已公告的 114 年度數據。114 年度因 CPI 漲幅 2.29% 未達 3% 門檻而免予調整，級距與 113 年度相同。實際申報請以財政部公告為準。
2. **健保投保金額級距表以連續上限近似** — 健保署 58 級距／12 投保金額對照表未逐級建入，改以「月薪資上限 313,000」計算，誤差低於健保費用 1%，影響稅後月薪不到 0.15%。

其他模型簡化（僅計薪資所得、僅採標準扣除額、未模擬加州 Schedule CA 州級調整、雇主提繳勞退 6% 不列入稅後月收入、生活成本假設單人獨居市中心一房、Numbeo 為群眾回報資料持續更新）同樣列在 App 內。
